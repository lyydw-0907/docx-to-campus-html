# Source Word Bold Restoration Implementation Plan

**Goal:** Match the original Word text and heading bold states, including inherited bold and explicit normal overrides, in both font modes.

**Architecture:** Resolve source OOXML bold properties before temporary style tagging. Record effective weight with run identities, then restore that weight in HTML without relying on the DOCX reader's inferred emphasis or default heading CSS. Preserve mathematics, images, field boundaries and other formatting.

**Tech Stack:** Node.js, Cheerio XML/HTML, JSZip, Pandoc JSON, isolated Edge via Playwright CLI.

**Constraints:** Original Word remains read-only; private text and paths stay in ignored output. No school session accesses, uploads, saves or submissions. Public tests use synthetic DOCX only.
