# 浏览器版：MathML 在线转换

浏览器版将 Pandoc WASM、页面脚本和合成示例打包为静态文件。转换在浏览器 Worker 中执行，保留 Word 原字号、加粗及样式继承、段落缩进与对齐、表格布局、已有公式编号、栏目拆分和普通图片地址映射。使用原生 MathML，公式不生成图片。

在线入口：[华农大创 Word 转 HTML](https://docx-to-campus-html.pages.dev/)。原本地版继续保留，使用 MathML/PNG 和本机 Pandoc。

## 构建与本机预览

开发构建与本机静态预览需要 Node.js 22 或更高版本。在项目目录执行：

```powershell
npm ci
npm run build:browser
npm run start:browser
```

随后打开 [http://127.0.0.1:4318/](http://127.0.0.1:4318/)。Windows 在完成依赖安装及构建后，也可双击项目根目录的 `start-browser.cmd`。启动器只提供静态文件，关闭启动窗口不会停止预览服务；日志位于 `output/browser-server/`。

`npm run preview:browser` 可在前台运行静态预览服务。浏览器版预览使用 4318 端口；`npm start` 或 `start-local.cmd` 启动的原本地转换服务使用 4317 端口。

构建生成：

- `output/browser/`：可直接托管的完整静态目录。
- `output/campus-mathml-browser.zip`：浏览器版静态文件包。

需要 Cloudflare 页面累计访问次数时，运行 `npm run build:cloudflare`，得到单独的 Cloudflare 包；需在实际项目中配置 D1 绑定和生产站点 origin 后启用，见 [访问次数部署说明](cloudflare-visits.md)。普通静态包默认不启用统计。

## 静态托管与浏览器要求

将 `output/browser/` 的完整内容发布到 HTTPS 静态托管服务，保持页面、Worker、转换引擎和合成示例的相对位置。资源路径支持站点子目录。托管服务须将 `.js` 作为 JavaScript 提供。页面根据响应字节识别压缩引擎；托管服务直接提供 `.gz` 文件或通过 `Content-Encoding: gzip` 提供时均不会重复解压。

公众打开托管网址即可使用，无需安装 Node.js 或本机 Pandoc。直接双击 `index.html` 不能启动此工具，应使用 HTTPS 网址或 localhost 静态预览。浏览器需要支持 WebAssembly、模块 Worker、Web Crypto、DecompressionStream 和图片解码 API，建议使用新版 Edge、Chrome 或 Firefox。

首次转换下载约 15.5 MB 的压缩引擎，随后在当前 Worker 中复用。加载和转换期间可点击“取消转换”，Worker 会停止；页面继续可操作，之后可重新转换。浏览器版保留 20 MB DOCX 输入限制，并检查 ZIP 实际解压大小、图片像素数及公式数量。

## 使用与数据处理

在“学校表单”选择“申报书”或“项目进展检查”，再选择或拖入一个 `.docx`，点击“转换文件”；也可使用当前表单对应的合成示例。默认保留 Word 原文字号，可改为统一字号。转换后选择学校栏目、参考文献等待分配片段或整篇文档，核对预览与源码。

进展检查有两个学校编辑框：“项目进展检查（项目执行的进展情况，取得了哪些成绩，是否达到预期效果，以及在项目的开展过程中还存在哪些问题）”与“项目后期具体工作计划”。第一栏在选择框中显示简称，完整标题可在预览说明中查看。Word 使用“项目进展检查”与“项目后期具体工作计划”两个同级、无编号的标题（例如均用“标题 1”样式），内部小标题使用下一层级；第一栏也识别学校的完整长标题。无法确定边界时保留整篇，按学校编辑框手动分配。工具不自动判断文件属于哪个表单。

原生 MathML 无需上传公式图片。普通图片仍通过学校编辑器的插图入口手工上传：先选择复制范围，下载本栏上传用图片，按原文图号上传，将本栏学校图片源码粘贴回工具，核对文件名匹配或确认顺序对应关系，再复制已替换地址的正文。只需完成当前范围的图片，其他栏目的缺失地址或未确认对应关系不会阻止它；下载包保留全篇原图号，图号可能不连续。切换栏目保留已填地址、源码和未确认的对应关系。整篇复制与完整映射包下载仍要求全部图片准备好。整篇保留封面、所有栏目和参考文献；栏目复制只移除对应的外层标签标题。预览继续使用原本地图片，学校 URL 只写入待复制或下载的 HTML。

Word、提取图片、粘贴的学校源码和学校图片 URL 在当前浏览器内存中处理；主动下载的转换包和进度文件保存在用户本机。工具不上传这些内容、不存入浏览器持久存储，也不调用学校上传、保存或提交接口。未启用访问统计时，网络请求用于本站页面、脚本、转换引擎与合成示例等静态资源；启用后，公开主页每次加载另发一个同源空 POST，只用于累计页面访问次数，不携带文档、学校内容、cookie 或访客标识。本地预览不计数。未保存工作进度时，刷新或关闭页面后需重新选择 Word；已保存时可导入进度文件继续。页面提供的学校图片查看链接由用户主动打开。

文本框、浮动图形、分页、页眉页脚及 MathType/OLE 公式等仍受转换引擎限制。公式数量不一致或引擎报告数学转换问题时停止导出；普通图片需使用支持的 PNG、JPEG、GIF 或 WebP，复杂布局仍需人工核对。

### 保存与恢复工作进度

转换后点击“保存工作进度”下载 ZIP。文件包含原 Word、本次转换实际使用的设置、当前复制范围、各栏学校图片源码和页面地址、手工图片地址，以及已确认或待确认的图片对应关系。未填完的手工地址、未确认的顺序调整和其他栏目的输入会一起保留。下拉设置的修改须重新转换后才写入进度。

下次在“恢复工作进度”选择该 ZIP，无需解压或重新选择 Word。工具先重新转换并核对正文、公式、图片和栏目，再恢复地址与顺序；待确认的对应关系仍需确认。取消恢复、损坏文件或核对不一致时，当前工作保留。浏览器版恢复 MathML 进度，PNG 进度使用原本地版。

页面不会自动保存，请在刷新或离开前主动保存。进度文件含原 Word 和输入内容，请妥善保管。
